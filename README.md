# Lustria Corporation site

Static multi-page site for GitHub Pages.

- `index.html` home
- `history.html`, `founders.html`, `industries.html`, `vision.html`, `join.html`
- `style.css` shared styles, `main.js` shared script (edit application links and Tug's profile at the top)
- `assets/` images

Deploy: push these files to the root of the `lustria-inc.github.io` repo (branch `main`), then Settings > Pages > Deploy from branch.
